C17Déployer un service

Déploiement de GLPI sur Azure

Réalisation : Déploiement d'un service GLPI sur une machine virtuelle Azure.

Compétence : Déployer un service informatique.

📋 Contexte
J'ai déployé GLPI sur Microsoft Azure afin de rendre le service accessible à distance dans un environnement proche d'une mise en production réelle, en maîtrisant le déploiement cloud d'une application web avec ses dépendances.
🔧 Démarche suivie
  • 1Création et configuration d'une machine virtuelle Linux sur Azure.
  • 2Installation du serveur web Apache et du moteur PHP.
  • 3Installation et sécurisation de la base de données MySQL.
  • 4Téléchargement, décompression et installation de GLPI.
  • 5Configuration de la base de données et des paramètres GLPI.
  • 6Ouverture des ports réseau (80/443) dans le pare-feu Azure.
  • 7Tests complets du bon fonctionnement de l'interface.
🛠️ Outils utilisés
Microsoft AzureLinux (Ubuntu)ApachePHPMySQLGLPISSH
✅ Conclusion
J'ai acquis des compétences solides en déploiement cloud : préparer un environnement serveur complet, installer une application web, configurer ses dépendances et vérifier son accessibilité. Expérience directement transposable en entreprise.
